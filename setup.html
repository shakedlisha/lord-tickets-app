המערכת מוכנה לשימוש

expand_more הגדרת Google Sign-In (אופציונלי)

שלב 1: היכנס ל-Google Cloud Console

שלב 2: צור פרויקט חדש (או בחר קיים)

שלב 3: הגדר OAuth Consent Screen:

  • בחר "External" User Type
  • הזן שם אפליקציה: "Lord Tickets"
  • הוסף Scopes: email, profile, openid

שלב 4: צור OAuth 2.0 Client ID:

  • Application type: Web application
  • Authorized redirect URI: https://YOUR_SUPABASE_PROJECT.supabase.co/auth/v1/callback

שלב 5: העתק את ה-Client ID וה-Client Secret

שלב 6: היכנס ל-Supabase Dashboard

  • בחר את הפרויקט שלך
  • לך ל-Authentication → Providers
  • הפעל את Google
  • הדבק את ה-Client ID וה-Client Secret
  • ב-Redirect URL, הוסף: https://YOUR_SITE.github.io/lord-tickets-app/index.html
  • שמור

זהו! כפתור Google Sign-In יעבוד אוטומטית.
