## System Overview

**Lord Tickets** is a travel agency system for managing flight inventory and generating customer quotes. It's built with pure HTML/CSS/JavaScript (no build tools) and uses Supabase as the backend database.

---

## Architecture

```
lord-tickets-app/
├── index.html              # Quote Generator - create customer quotes
├── inventory.html          # Inventory Manager - manage flight stock
├── view.html               # Public view for shared quotes
├── gmail-to-drive-script.js # Google Apps Script for email automation
├── SETUP_GMAIL_IMPORT.md   # Gmail import instructions
└── supabase/
    └── migrations/
        ├── 001_create_tables.sql    # Core tables
        ├── 002_public_view.sql      # Public API view
        ├── 003_booking_function.sql # Booking logic
        └── 004_rls_policies.sql     # Row-level security
```

---

## Two Main Modules

| Module | File | Purpose |
|--------|------|---------|
| **Quote Generator** | `index.html` | Create travel quotes for customers, add flights/hotels/services, calculate prices with commission, generate shareable links |
| **Inventory Manager** | `inventory.html` | Full CRUD for flights, Excel-like inline editing, real-time sync, CSV import/export |

---

## Database Schema (Supabase/PostgreSQL)

| Table | Purpose |
|-------|---------|
| `flights` | Master flight inventory (dates, airline, seats, pricing) |
| `quotes` | Customer quotes with status tracking |
| `quote_flights` | Links quotes to flights |
| `bookings` | Confirmed sales/reservations |
| `audit_log` | Change tracking |

---

## Key Features

- **Hebrew RTL Support** - Full right-to-left interface
- **Gold/Navy Theme** - Professional travel agency styling
- **AI Parsing** - Google Gemini API for text/image parsing
- **Real-time Sync** - Supabase real-time subscriptions
- **No Build Required** - Open HTML files directly in browser
